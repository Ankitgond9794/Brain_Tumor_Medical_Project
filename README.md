# Brain Tumor Medical Project

## Overview
This project is a Brain Tumor Classification system developed using Deep Learning and TensorFlow. It classifies brain MRI images into different tumor categories.

## Features
- Brain MRI image classification
- Deep Learning model
- TensorFlow/Keras implementation
- Image preprocessing
- Model prediction

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- OpenCV
- Matplotlib
- Streamlit

## Dataset
The dataset contains MRI images divided into:
- Training
- Testing

Classes:
- Glioma
- Meningioma
- Pituitary
- No Tumor

## How to Run

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the Streamlit app:
```bash
streamlit run app.py
```
